# 시험 끝! 게임 모음

시험이 끝난 교실에서 친구들과 가볍게 즐기는 **3D 웹 게임 모음**입니다.
설치 없이 브라우저(학교 PC, 크롬북, 스마트폰)에서 바로 실행되고, 각자 폰으로 **방 코드**를 넣어 같은 방에서 함께 할 수 있습니다.

| 게임 | 인원 | 시간 | 한 줄 소개 |
|---|---|---|---|
| [시험 끝! 타일 배틀](games/tile-battle/) | 3~5명 | 15~25분 | 숫자 타일로 겨루는 클라이밍 게임. 혼자 AI와 연습, 한 기기 돌려 하기, 온라인 방 |
| [심해 보물섬 탐험대](games/deep-sea/) | 4~6명 | 10~15분 | 숨은 역할 카드 게임. 탐험대는 보물을, 해적은 심해 대왕문어를 노림. 온라인 방, 봇과 연습 |

공통 기능: Three.js 3D 장면, Web Audio로 합성한 소리(외부 사운드 파일 없음), 건너뛸 수 있는 인터랙티브 튜토리얼, 모바일 세로 화면, 저사양 PC용 그래픽 옵션.

## 폴더 구조

```
index.html, hub.js, hub.css   첫 화면: 게임 고르기 + 방 코드로 참여 (코드를 넣으면 어떤 게임인지 찾아서 이동)
games/tile-battle/            시험 끝! 타일 배틀
games/deep-sea/               심해 보물섬 탐험대
shared/                       공용 코드
  config.js                   온라인 서버 주소 (ONLINE_URL)
  net.js                      서버 호출
  lobby.js                    공용 대기방 화면 (방 만들기, 코드 참여, 봇, 방장, 폴링)
  ui-core.css / ui-core.js    OMR 답안지 디자인, 모달·토스트·배너·컨페티
  audio-core.js               Web Audio 합성 기본기
  anim.js, storage.js         트윈 엔진, localStorage 래퍼
server/
  core.js                     공용 대기방 서버 (앱스크립트)
  games/tile-battle.js        타일 배틀 서버 규칙 모듈
  games/deep-sea.js           심해 보물섬 서버 규칙 모듈
  Code.gs                     앱스크립트에 붙여 넣을 완성 파일 (자동 생성)
tools/
  build-gs.mjs                server/Code.gs 만들기
  dev-server.mjs              로컬 개발 서버 (앱스크립트 흉내)
```

> 예전 주소와 초대 링크도 그대로 동작합니다. `…/tile-battle/?room=1234`처럼 루트로 온 초대 링크는 허브가 방을 찾아 맞는 게임으로 보내 줍니다.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**에서 **Branch: `main` / `(root)`**로 설정합니다(이미 설정되어 있음).
2. `main`에 푸시하면 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에 반영됩니다.
3. 새 기능은 `feature/…` 브랜치에서 만들고 테스트한 뒤 `main`에 합치세요. 그래야 만드는 동안 학생들이 쓰는 사이트가 깨지지 않습니다.

## 온라인 대기방 설정 (구글 시트 + 앱스크립트)

GitHub Pages에는 서버가 없어서, 구글 앱스크립트 웹 앱 **하나**를 모든 게임의 공용 서버로 씁니다.
방 만들기·참여·봇·폴링은 공용이고, 게임별 규칙은 서버 모듈이 처리합니다. 역할이나 카드 위치 같은 숨김 정보는 서버에만 있고, 각자에게는 자기 것만 내려갑니다.

### 처음 설정 (한 번만)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 [`server/Code.gs`](server/Code.gs) 내용을 전부 붙여 넣고 저장합니다.
   - [script.new](https://script.new)에서 독립 스크립트로 만들었다면, 위쪽 `const SHEET_ID = '';`에 시트 ID(시트 주소의 `/d/`와 `/edit` 사이)를 넣으세요.
3. **배포 → 새 배포 → 웹 앱**을 고르고, 실행 계정 **나**, 액세스 권한 **모든 사용자**로 배포합니다.
4. 권한을 승인합니다. "확인되지 않은 앱"이 나오면 **고급 → (프로젝트)(으)로 이동**을 누르세요. 직접 만든 스크립트라서 나오는 안내입니다.
5. 나온 웹 앱 URL(`…/exec`)을 [`shared/config.js`](shared/config.js)의 `ONLINE_URL`에 넣고 커밋·푸시합니다.

### 서버 코드를 고친 뒤 (URL 그대로 유지)

**새 배포를 만들면 URL이 바뀌니 하지 마세요.** 대신:

1. `node tools/build-gs.mjs`로 `server/Code.gs`를 다시 만듭니다.
2. 앱스크립트 편집기에서 코드를 통째로 바꿔 붙여 넣고 저장합니다. 독립 스크립트라면 `SHEET_ID`를 다시 채우세요.
3. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 누릅니다.
4. 권한 범위가 바뀌었다면 승인 창이 한 번 더 뜰 수 있습니다.

시트의 **`방 기록`** 탭에는 방 생성, 게임 시작, 결과가 한 줄씩 남습니다(시간, 방 코드, 게임, 닉네임, 내용).

**알아두면 좋은 점**
- 방 상태는 앱스크립트 캐시에 6시간 보관됩니다.
- 45초 넘게 연결이 끊긴 사람이나 게임 중에 나간 사람은 봇이 대신 둡니다.
- 무료 앱스크립트는 **동시 실행 30개** 제한이 있습니다. 한 반(30명 안팎, 방 6~8개)이 적당하고, 한 수가 1~2초 늦게 반영될 수 있습니다.
- 시트에 닉네임이 남으니 실명 대신 별명을 쓰도록 안내해 주세요.

## 로컬에서 실행하기

```powershell
node tools/dev-server.mjs
```

http://localhost:5173/?api=/api 를 엽니다. `?api=/api`를 붙이면 진짜 앱스크립트 대신 같은 서버 코드를 로컬에서 돌립니다. 탭을 여러 개 열어 방장과 친구 역할을 해 볼 수 있습니다.

- 자가 테스트: 각 게임 주소에 `?test`를 붙이면 콘솔에 규칙 테스트 결과가 찍힙니다.
  - 타일 배틀: 족보 판정 20개
  - 심해 보물섬: 역할 수, 카드 구성, 라운드별 장수, 승리 조건, 무작위 2,000판 카드 보존 등 18개

## 새 게임 추가하기 (체크리스트)

1. **게임 폴더**: `games/<id>/index.html`, `style.css`, `js/` 를 만듭니다.
   - `../../shared/ui-core.css`를 불러오고, `#modal`, `#toast`, `#banner`, `#confetti`를 넣습니다.
   - 저장소는 `createStore('<id>:')`로 접두어를 따로 씁니다.
2. **규칙 엔진**: `games/<id>/js/rules.js`에 순수 함수로 작성합니다(DOM 없이). 서버와 브라우저가 같이 씁니다. `runSelfTests()`도 넣어 두세요.
3. **서버 모듈**: `server/games/<id>.js`에서 `registerGame('<id>', { title, minPlayers, maxPlayers, reset, start, act, actor, botDelay, botMove, view, playerView })`를 구현합니다.
   - `view()`에는 **그 사람에게 보여도 되는 정보만** 넣으세요.
4. **빌드 등록**: `tools/build-gs.mjs`의 `LIBS`(브라우저 모듈)와 `MODULES`(서버 모듈)에 한 줄씩 추가하고 `node tools/build-gs.mjs`를 실행합니다.
5. **클라이언트**: `new Lobby({ game: '<id>', title, onGameState, onLeaveGame, onBack })`로 대기방을 붙이고, `onGameState(state, isFirst)`에서 화면을 그립니다.
6. **허브**: `index.html`에 게임 카드를, `hub.js`의 `GAME_PATH`에 경로를 추가합니다.
7. **검증**: 로컬 개발 서버에서 여러 탭으로 끝까지 해 보고, 기존 게임도 한 번씩 확인한 뒤 앱스크립트를 새 버전으로 배포합니다.

## 오리지널 디자인 고지

- **타일 배틀**: 빅투·티엔렌 계열의 전통 클라이밍 규칙을 바탕으로 했습니다.
- **심해 보물섬 탐험대**: 숨은 역할 + 카드 뒤집기 장르의 일반적인 규칙을 바탕으로 했습니다.
- 두 게임의 이름, 로고, 캐릭터(탐험대원, 해적, 심해 대왕문어), 카드·타일 그림, 효과음, 배경음은 모두 이 프로젝트에서 새로 만들었습니다. 특정 상업 보드게임의 이름, 캐릭터, 아트, 문구, 패키지 디자인은 사용하지 않았습니다.
