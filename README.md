# 시험 끝! 타일 배틀

시험이 끝난 교실에서 친구들과 가볍게 즐기는 **3D 타일 클라이밍 게임**입니다.
설치 없이 브라우저(학교 PC, 크롬북, 스마트폰)에서 바로 실행됩니다.

- 🎲 Three.js로 만든 3D 원목 테이블과 타일, 포물선을 그리며 날아가는 타일 연출
- 🔊 Web Audio로 직접 합성한 효과음과 로파이 배경음 (외부 사운드 파일 없음)
- 🎓 6단계 인터랙티브 튜토리얼 (언제든 건너뛰기 / 다시 보기)
- 🤖 AI 대전(쉬움·보통·어려움) + 👥 한 기기로 돌려 하는 핫시트 모드
- 📱 모바일 세로 화면, 저사양 PC용 그래픽 품질 옵션

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 타일 | 숫자 1~15 × 문양 4개. 3명은 1~9, 4명은 1~13, 5명은 1~15 사용 |
| 나누기 | 쓰는 타일을 모두 나눔 (3·5명 12장, 4명 13장) |
| 숫자 세기 | 3 < 4 < … < 최대숫자 < 1 < **2** |
| 문양 세기 | ☁ 구름 < ★ 별 < ☾ 달 < ☀ 해 |
| 시작 | 구름 3을 가진 사람이 먼저, 첫 수에 구름 3 포함 |
| 진행 | 바닥과 같은 장수로 더 센 조합을 내거나 패스. 나머지 모두 패스하면 마지막에 낸 사람이 새로 시작 |
| 조합 | 싱글 · 페어 · 트리플 / 5장: 스트레이트 < 플러시 < 풀하우스 < 포카드 < 스트레이트 플러시 |
| 스트레이트 | 1-2-3-4-5 최강, 2-3-4-5-6 두 번째, 나머지는 가장 높은 숫자로 비교 |
| 점수 | 남은 장수 × 2^(손에 남은 2의 수). 모든 두 사람이 점수 차이만큼 칩을 주고받음 |
| 끝 | 정한 라운드 수(기본 5판)가 끝나거나 누군가 칩이 0 이하가 되면 종료 |

**조작**: 타일을 눌러 고르고 [내기]. 키보드 단축키는 `Enter` 내기, `P` 패스, `H` 힌트입니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 **공개(Public)** 저장소를 만듭니다.
2. 이 폴더의 파일을 그대로 올립니다: `index.html`, `style.css`, `js/`, `README.md`, `.gitignore`
3. 저장소에서 **Settings → Pages**로 갑니다.
4. **Source: Deploy from a branch**, **Branch: `main` / `(root)`**를 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다. QR코드로 만들어 학생들에게 나눠 주세요.

> 모든 경로가 상대경로라서 `/<저장소이름>/` 아래에서도 그대로 동작합니다.
> Three.js(0.160.0)와 글꼴은 CDN(jsdelivr, Google Fonts)에서 불러옵니다. 학교망에서 이 주소가 막혀 있으면 화면이 뜨지 않으니 먼저 확인해 주세요.

## 로컬에서 실행하기

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 실행되지 않습니다. 간단한 서버로 여세요.

```powershell
npx http-server -p 5173 -c-1
```

그다음 http://localhost:5173 을 엽니다. `http://localhost:5173/?test`로 열면 족보 판정 자가 테스트 결과가 콘솔에 찍힙니다.

## 파일 구조

```
index.html        화면 뼈대, importmap
style.css         OMR 답안지 + 칠판 펠트 디자인
js/main.js        초기화, 화면 전환, 설정
js/game.js        딜, 차례, 내기/패스, 정산, 최종 순위
js/rules.js       족보 판정과 비교 (순수 함수) + 자가 테스트
js/ai.js          AI 난이도 3단계, 힌트
js/scene.js       Three.js 테이블, 조명, 카메라, 손패 배치, 연출
js/tiles.js       타일 메시와 CanvasTexture (문양을 직접 그림)
js/anim.js        트윈 엔진
js/audio.js       Web Audio 효과음과 배경음
js/tutorial.js    단계형 튜토리얼
js/ui.js          HTML 오버레이 (이름표, 모달, 토스트, 강약표)
js/storage.js     localStorage 래퍼
```

## 오리지널 디자인 고지

이 게임은 빅투·티엔렌 계열의 전통적인 클라이밍 규칙을 바탕으로 만들었습니다.
게임 이름, 로고, 문양(구름·별·달·해), 타일과 뒷면(OMR 마킹 무늬) 디자인, 효과음, 배경음은 모두 이 프로젝트에서 새로 만든 것이며,
특정 상업 보드게임의 이름, 로고, 아트, 패키지 디자인은 사용하지 않았습니다.
