# 시험 끝! 타일 배틀

시험이 끝난 교실에서 친구들과 가볍게 즐기는 **3D 타일 클라이밍 게임**입니다.
설치 없이 브라우저(학교 PC, 크롬북, 스마트폰)에서 바로 실행됩니다.

- 🎲 Three.js로 만든 3D 원목 테이블과 타일, 포물선을 그리며 날아가는 타일 연출
- 🔊 Web Audio로 직접 합성한 효과음과 로파이 배경음 (외부 사운드 파일 없음)
- 🎓 6단계 인터랙티브 튜토리얼 (언제든 건너뛰기 / 다시 보기)
- 🌐 온라인 방: 4자리 코드나 초대 링크로 각자 폰에서 같은 방에 참여 (구글 앱스크립트 서버)
- 🤖 AI 대전(쉬움·보통·어려움) + 👥 한 기기로 돌려 하는 핫시트 모드
- 📱 모바일 세로 화면, 저사양 PC용 그래픽 품질 옵션

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 타일 | 숫자 1~15 × 문양 4개. 3명은 1~9, 4명은 1~13, 5명은 1~15 사용 |
| 나누기 | 쓰는 타일을 모두 나눔 (3·5명 12장, 4명 13장) |
| 숫자 세기 | 3 < 4 < … < 최대숫자 < 1 < **2** |
| 문양 세기 | ☁ 구름 < ★ 별 < ☾ 달 < ☀ 해 |
| 시작 | 구름 3을 가진 사람이 먼저, 첫 수에 구름 3 포함 |
| 진행 | 바닥과 같은 장수로 더 센 조합을 내거나 패스. 나머지 모두 패스하면 마지막에 낸 사람이 새로 시작 |
| 조합 | 싱글 · 페어 · 트리플 / 5장: 스트레이트 < 플러시 < 풀하우스 < 포카드 < 스트레이트 플러시 |
| 스트레이트 | 1-2-3-4-5 최강, 2-3-4-5-6 두 번째, 나머지는 가장 높은 숫자로 비교 |
| 점수 | 남은 장수 × 2^(손에 남은 2의 수). 모든 두 사람이 점수 차이만큼 칩을 주고받음 |
| 끝 | 정한 라운드 수(기본 5판)가 끝나거나 누군가 칩이 0 이하가 되면 종료 |

**조작**: 타일을 눌러 고르고 [내기]. 키보드 단축키는 `Enter` 내기, `P` 패스, `H` 힌트입니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 **공개(Public)** 저장소를 만듭니다.
2. 이 폴더의 파일을 그대로 올립니다: `index.html`, `style.css`, `js/`, `README.md`, `.gitignore`
3. 저장소에서 **Settings → Pages**로 갑니다.
4. **Source: Deploy from a branch**, **Branch: `main` / `(root)`**를 고르고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다. QR코드로 만들어 학생들에게 나눠 주세요.

> 모든 경로가 상대경로라서 `/<저장소이름>/` 아래에서도 그대로 동작합니다.
> Three.js(0.160.0)와 글꼴은 CDN(jsdelivr, Google Fonts)에서 불러옵니다. 학교망에서 이 주소가 막혀 있으면 화면이 뜨지 않으니 먼저 확인해 주세요.

## 온라인 대기방 설정 (구글 시트 + 앱스크립트)

**온라인 방** 메뉴에서는 각자 자기 폰으로 같은 방에 들어와 함께 할 수 있습니다. 한 사람이 방을 만들고 4자리 코드나 초대 링크를 알려 주면 됩니다.
GitHub Pages에는 서버가 없어서, 구글 앱스크립트를 무료 서버로 씁니다. **처음 한 번만** 설정하면 됩니다(약 5분).

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `타일 배틀 서버`
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고, 이 저장소의 [`server/Code.gs`](server/Code.gs) 내용을 전부 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형 선택(⚙️)에서 **웹 앱**을 고릅니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인합니다. "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 내가 직접 만든 스크립트라서 나오는 안내입니다.
6. 화면에 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. 이 저장소의 `js/config.js`를 열어 `ONLINE_URL = '여기에 붙여넣기'`로 바꾸고 커밋·푸시합니다. GitHub 웹에서 연필 아이콘으로 바로 고쳐도 됩니다.

설정이 끝나면 시트에 **`방 기록`** 탭이 생기고, 방을 만들거나 게임이 끝날 때마다 한 줄씩 남습니다(시간, 방 코드, 닉네임, 결과).

**알아두면 좋은 점**
- 실시간 상태는 앱스크립트 캐시에 6시간 보관되고, 그 뒤 방은 자동으로 사라집니다.
- 패를 나누고 규칙을 검사하는 일은 서버가 합니다. 그래서 다른 사람의 패는 개발자 도구로도 볼 수 없습니다.
- 인원이 모자라면 방장이 봇(쉬움·보통·어려움)을 넣을 수 있습니다. 게임 중에 나간 사람이나 45초 넘게 연결이 끊긴 사람은 봇이 대신 둡니다.
- 무료 계정의 앱스크립트는 동시에 처리할 수 있는 요청 수에 한도가 있습니다. **한 반(30명 안팎, 방 6~8개)** 정도가 적당합니다. 수가 1초쯤 늦게 반영될 수 있습니다.
- 시트에 닉네임이 기록되니, 학생들에게 실명 대신 별명을 쓰도록 안내해 주세요.
- `server/Code.gs`를 바꾼 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로입니다.

> `server/Code.gs`는 `js/rules.js`, `js/ai.js`, `server/room.js`를 합쳐 자동으로 만든 파일입니다. 규칙을 고쳤다면 `node tools/build-gs.mjs`로 다시 만드세요.

## 로컬에서 실행하기

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 실행되지 않습니다. 간단한 서버로 여세요.

```powershell
npx http-server -p 5173 -c-1
```

그다음 http://localhost:5173 을 엽니다. `http://localhost:5173/?test`로 열면 족보 판정 자가 테스트 결과가 콘솔에 찍힙니다.

온라인 방까지 로컬에서 시험하려면, 앱스크립트를 흉내 내는 개발 서버를 쓰세요. 탭 두 개를 열어 방장과 친구 역할을 해 볼 수 있습니다.

```powershell
node tools/dev-server.mjs
```

그다음 http://localhost:5173/?api=/api 를 엽니다.

## 파일 구조

```
index.html        화면 뼈대, importmap
style.css         OMR 답안지 + 칠판 펠트 디자인
js/main.js        초기화, 화면 전환, 설정
js/game.js        딜, 차례, 내기/패스, 정산, 최종 순위
js/online.js      온라인 대기방과 온라인 대전 화면
js/net.js         앱스크립트 서버와 주고받기
js/config.js      온라인 서버 주소 (ONLINE_URL)
server/room.js    대기방 서버 로직 (앱스크립트)
server/Code.gs    앱스크립트에 붙여 넣을 완성 파일 (자동 생성)
tools/            Code.gs 만들기, 로컬 개발 서버
js/rules.js       족보 판정과 비교 (순수 함수) + 자가 테스트
js/ai.js          AI 난이도 3단계, 힌트
js/scene.js       Three.js 테이블, 조명, 카메라, 손패 배치, 연출
js/tiles.js       타일 메시와 CanvasTexture (문양을 직접 그림)
js/anim.js        트윈 엔진
js/audio.js       Web Audio 효과음과 배경음
js/tutorial.js    단계형 튜토리얼
js/ui.js          HTML 오버레이 (이름표, 모달, 토스트, 강약표)
js/storage.js     localStorage 래퍼
```

## 오리지널 디자인 고지

이 게임은 빅투·티엔렌 계열의 전통적인 클라이밍 규칙을 바탕으로 만들었습니다.
게임 이름, 로고, 문양(구름·별·달·해), 타일과 뒷면(OMR 마킹 무늬) 디자인, 효과음, 배경음은 모두 이 프로젝트에서 새로 만든 것이며,
특정 상업 보드게임의 이름, 로고, 아트, 패키지 디자인은 사용하지 않았습니다.
